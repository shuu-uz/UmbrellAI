# 우산 설문 분석: 박다연

## 실행
Python 환경에서 `python -m pip install pandas scipy`를 실행한 뒤,
이 폴더와 원본 설문 CSV를 같은 위치에 두세요.
`python analyze.py "원본.csv"`를 실행하면 결과 파일이 생성됩니다.
원본 CSV는 수정하지 않습니다. 포함된 결과는 제공된 80개 응답으로 실행한 것입니다.

## 전처리
80명, 원본 16열. 공백 제거, 열 이름 변경, 불편도 1~5점 범위 검사,
객관식 응답 검사, 중요도 1~5점 변환. 원본 및 전처리 후 결측치 0개.
대응표본 분석에서 제외한 응답 0개. 같은 선택 패턴만으로 중복 응답을 삭제하지 않았습니다.
column_mapping.csv에 원본 질문과 변경 열 이름이 있습니다.
실제 체류 시간을 수집하지 않았으므로 15분 단위 범주화는 수행하지 않았습니다.
10분/60분은 가상 시나리오이며 응답자 속성으로 해석하지 않습니다.

## 대응표본 T-test
귀무가설: 비맞음과 우산짐 불편도의 모집단 평균 차이가 0이다.
양측 검정, 유의수준 0.05. 같은 응답자의 두 점수를 비교합니다.
우산짐 평균 3.900, 비맞음 평균 4.125, 평균 차이(비맞음-우산짐) 0.225.
t(79)=1.3562, p=0.1789.
평균 차이의 95% 신뢰구간 [-0.1052, 0.5552].
귀무가설을 기각하지 못했습니다. 차이가 없다는 증명은 아닙니다.
서열척도 특성을 고려한 Wilcoxon 보완 검정도 p=0.1703으로 유의하지 않았습니다.
표본 모집 방식과 응답자 대표성은 확인되지 않았으므로 전체 사용자로 일반화하지 않습니다.

## 기준점
이전 대화에서 제시한 비용 모형의 탐색적 값은
3.90/(3.90+4.125)=0.486입니다.
비가 오지 않을 때 우산을 들고 다니는 비용과 비가 올 때 비를 맞는 비용만 고려합니다.
1~5점은 서열척도이며 0점이 없어 비율 비용으로 쓰는 데 한계가 있습니다.
따라서 48.6%를 확정 추천 기준으로 채택하거나 T-test로 검증됐다고 해석하지 않습니다.
설문 7번의 직접 응답 분포와 추가 실제 사용 검증이 필요합니다.
