# UmbrellAI 데모 실행·발표 안내

## 실행
`UmbrellAI_demo.html`을 Chrome 또는 Edge로 연다. 서버·설치·인터넷이 필요 없는 단일 파일이다. 새로고침하면 초기 상태로 돌아간다. 외부 GitHub 출처 링크를 직접 누르면 인터넷이 필요하다.

## 2~3분 시연
1. 설문 탭 POP50 기본 31.32점에서 이동을 60분으로 바꿔 64.77점을 보여준다. ‘같은 강수확률에서도 이동 조건에 따라 응답 의향이 달라집니다.’
2. 우산짐·비맞음 불편도를 바꾼다. ‘개인 선호를 입력에 반영한 모델입니다. 실제 우산 필요 확률로 해석하지 않습니다.’
3. 하루 POP60 조건에서 비 예보 없음 43.78점 → 있음 86.43점을 보여준다.
4. 과거 예보 탭의 10월 13일 등교에서 60% → 70%로 바꾸고 실측을 공개한다. ‘기준이 높아지면 이 강수 구간을 놓칩니다.’
5. 44구간 전체 결과를 펼친다. ‘무강수 42, 강수 2구간의 제한된 사례입니다. 기준을 높이면 헛경보가 줄어도 놓침이 생길 수 있습니다. 개인화의 성능 이점은 확정되지 않았습니다.’

## 재빌드·자동 검증
저장소 루트에서 Python과 Node.js가 있는 개발 환경으로 실행한다. 발표용 HTML 실행에는 둘 다 필요 없다.

```powershell
python demo/build_demo.py
python -m unittest discover -s tests -v
```

배포 파일은 `docs/demo/index.html`이다. GitHub Pages에서 해당 브랜치의 `/docs`를 게시하면 `/UmbrellAI/demo/` 경로를 사용한다. 실제 활성화 여부는 저장소 설정과 배포 상태를 확인해야 한다.

## 검증 기록 (2026-11-25)
자동 검증: 기존 분석 테스트와 신규 데모 테스트 총 23개. 신규 검증은 지원 입력 100개 Python 대조, 반올림 전 11자리 비교, 44구간 오류 집계, 잘못된 입력 거절, 단일 HTML 의존성·JS 문법 확인을 포함한다.

화면 검증 한계: 자동화 브라우저에서 로컬 파일/localhost 접근 및 새 Chrome 탭 연결이 실패하여 실제 렌더링·좁은 화면·키보드·오프라인 직접 실행 검증은 완료하지 못했다. 발표 전 HTML을 직접 열어 위 시연 순서와 초기화·탭 이동·실측 공개, 창 폭을 줄였을 때 배치를 확인해야 한다. 테스트 통과를 브라우저 검증 완료로 해석하지 않는다.
