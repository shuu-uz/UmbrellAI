## 1. 모델 결과표와 Brier 불확실성 분석 일치

기존 POP 50% 결과표는 `StratifiedGroupKFold(5, shuffle=True, random_state=42)`의 예측을 사용했지만, 추가 불확실성 분석은 별도의 `GroupKFold(5)`로 예측을 다시 만들어 계산했다. 이번 수정은 **기존 결과표의 점추정치를 유지하고, 그 표를 만든 것과 동일한 예측값으로 재표집 분석을 맞춘 것**이다.

최종 분석에 사용한 원본 설문 CSV의 SHA-256이 기록된 입력 해시와 일치하는지 확인했다. 두 조건의 Brier·정확도·ROC-AUC를 기존 결과 JSON과 대조해 모두 일치함을 확인한 뒤 구간을 계산했다. 개인별 답변·예측값은 공개 산출물에 추가하지 않았다.

| 조건 | 기준 Brier | 개인화 Brier | 차이: 개인화−기준 | 조건부 95% 구간 |
|---|---:|---:|---:|---:|
| POP 50% | 0.2274 | 0.2082 | −0.0192 | [−0.0474, +0.0119] |
| 하루 POP 60% | 0.2026 | 0.1903 | −0.0124 | [−0.0297, +0.0050] |

원문 표의 하루 POP 60% 값 0.203·0.190은 위 수치를 소수 셋째 자리까지 표시한 것으로, 원래 표나 그래프를 바꿀 필요는 없다. 정확도·ROC-AUC도 변경하지 않았다.

### 방법론 3.5에 넣을 문구 — PDF 8쪽

> POP 50% 조건은 응답자 단위 층화 그룹 5분할 교차검증(StratifiedGroupKFold, shuffle=True, random_state=42), 하루 POP 60% 조건은 그룹 5분할 교차검증(GroupKFold)을 사용하였다. 각 조건에서 기준 모델과 개인화 모델은 동일 분할을 사용하였다. 표준화는 각 학습 분할에서만 수행했고, L2 로지스틱 회귀(C=1, max_iter=2000)를 사용하였다. 추가 불확실성 분석에는 결과표를 산출한 것과 동일한 분할 밖 예측값을 사용하였다. 각 응답자의 두 상황을 묶어 개인화−기준 Brier 오차 차이의 응답자별 평균을 구하고, 응답자를 복원추출하는 5,000회 재표집(seed=42)으로 백분위 95% 구간을 계산하였다. 예측값은 고정했으므로 이 구간은 해당 내부 검증 예측에 조건부이며, 재학습 변동이나 외부 일반화의 불확실성을 모두 반영하지는 않는다.

### 결과 4.4에 넣을 문구 — PDF 13쪽

> 개인화−기준 Brier 오차 차이는 POP 50%에서 −0.0192(조건부 95% 구간 −0.0474~+0.0119), 하루 POP 60%에서 −0.0124(−0.0297~+0.0050)였다. 음수는 개인화 모델의 오차가 더 작음을 뜻하지만 두 구간 모두 0을 포함하였다. 따라서 내부 검증에서 수치상 개선이 관찰됐으나 개인화의 성능 이점을 확정하기에는 근거가 충분하지 않았다.

두 조건의 분할 방식이 다르므로 조건 간 성능 자체의 우열을 주장하지 않는다. 각 조건 안에서 기준 모델과 개인화 모델을 비교한다.

## 2. 개인 기준 적용 결과에 전체 평균 비교 추가 — PDF 15~16쪽

기존 `commute_results/policies.csv`의 전체 행을 그대로 사용했다. 각 응답자에게 동일한 가상 이동 44구간을 적용한 오류 횟수의 평균이다.

| 방식 | 1인당 44구간 평균 헛경보 | 평균 놓침 |
|---|---:|---:|
| 공통 60% 기준 | 2.00회 | 0.00회 |
| 개인 직접응답 기준 | 4.59회 | 0.83회 |

> 같은 44구간에 적용했을 때 개인 직접응답 기준의 전체 평균 헛경보와 놓침은 각각 4.59회·0.83회로, 공통 60% 기준의 2.00회·0.00회보다 적지 않았다. 따라서 이 표본에서 개인 기준 적용이 전체 오류를 줄였다고 주장하지 않는다. 다만 오류 횟수만으로 사용자별 선호 충족이나 만족도를 평가한 것은 아니며, 실제 효용 검증에는 별도 행동·만족도 자료가 필요하다.

반올림 전 전체 평균은 4.5875와 0.825이다. 집단별 반올림 수치를 다시 합산하지 않고 원래 전체 집계를 사용했다.

## 3. 분석 구조 설명 추가 — PDF 3쪽 또는 8~9쪽

> 본 연구는 예보·실측 평가, 설문 기반 지참 의향 추정, 실제 예보에 개인 임계값을 적용한 시연의 세 부분으로 구성된다. 기상자료와 설문은 실제 외출 사건별로 연결되지 않아 회귀모델은 설문 문항으로 학습하였다. 실제 등·하교 예보에 대한 적용은 회귀모델과 별도의 개인 임계값 규칙으로 수행하였다.

도식의 세 경로:

- 예보 + 실측 → 예보 평가
- 설문 조건 + 두 불편도 → 지참 의향 회귀모델
- 실제 시간대 예보 + 설문의 직접응답 기준 → 규칙 기반 적용 시연
