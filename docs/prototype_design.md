# UmbrellAI 발표용 프로토타입 설계

자료 기준: 2026-11-23 분석 산출물 / 구현: 2026-11-25

## 목적과 범위
평가자가 이동 조건과 개인 선호를 바꿔 설문 기반 지참 의향과 규칙 기반 권고를 구분해서 이해하는 한국어 데모다. 단일 HTML에 모델 계수와 저장 사례를 포함하여 인터넷 없이 실행한다. 실시간 예보, 로그인, 기록 저장, 재학습은 제공하지 않는다.

## 설문 기반 지참 의향
입력과 결과를 가로 화면에서 좌우, 좁은 화면에서 위아래로 배치한다.

| 조건 | 변경 가능한 이동 조건 | 기본 불편도(우산짐/비맞음) | 기본 점수 |
|---|---|---|---|
| POP 50% | 야외 이동 10분 / 60분 | 4 / 4 | 31.32 / 64.77 |
| 하루 POP 60% | 이동 시간대 비 예보 없음 / 있음 | 3 / 4 | 43.78 / 86.43 |

불편도는 각각 정수 1~5점이다. 고정 POP와 미지원 이동 시간을 자유 입력하지 않는다. 변경 즉시 기존 로지스틱 회귀식으로 계산하고 초기화 버튼을 제공한다. 점수는 해당 가상 상황에서 ‘챙긴다’고 응답할 의향 추정치이며 실제 강수 확률이나 우산 필요 확률이 아니다. 점수에 따른 자동 지참 판정은 없다.

모델 비교 펼침 영역에서 Brier, ROC-AUC, 정확도를 각각 표시한다. 조건 간 순위를 매기지 않고 ‘개인화의 성능 이점은 확정되지 않았다’를 명시한다.

## 과거 예보 적용 시연
44개 가상 등·하교 구간의 저장 예보와 실측을 사용한다. 날짜와 등교/하교를 함께 선택한다. 기본은 2026-10-13 등교, 개인 기준 60%다. 개인 기준은 20~90%의 10% 간격과 항상 지참이다.

권고는 `최고 POP >= 개인 기준`이며 항상 지참은 모든 구간에서 지참한다. 회귀 점수는 사용하지 않는다. 최고 POP는 구간 전체에서 한 번이라도 비가 올 확률이 아니다. 실측은 버튼으로 공개하며 공개 전후 권고는 동일하다. 공개 시 강수 적중·헛경보·놓침·무강수 적중을 구분한다. 전체 비교는 현재 기준과 공통 60%의 헛경보·놓침을 표시하며 무강수 42구간·강수 2구간을 함께 명시한다.

## 데이터와 구현
- POP50: `results/final_20261123/intention_model.json`의 평균·척도·계수·절편.
- POP60: 같은 폴더 `rain_score.json`의 계수·절편.
- 비교: `survey_metrics.json`, `rain_score.json` 검증값 그대로 사용.
- 사례: `commute_results/windows.csv` 날짜·구간·최고 POP·실측 여부.
- 개인 원본 설문 응답과 개인별 예측값은 포함하지 않는다.

`demo/build_demo.py`가 자료를 읽어 `demo/template.html`과 `demo/core.js`를 결합한다. 모델·사례 스키마와 수치가 다르면 실패하며 대체값을 만들지 않는다. 산출물은 `docs/demo/index.html`과 작업 폴더의 `outputs/UmbrellAI_demo.html`이다. 실행 중 fetch, CDN, API, 영구 저장은 없으며 CSP의 connect-src도 none이다. 자료 출처에 분석 기준일, 빌드 기준 Git 버전과 데모 소스 해시를 표시한다.

## 디자인과 조작
밝은 배경, 남색 강조, 큰 결과 숫자와 버튼을 사용한다. 레이블·선택 상태·문자 결과와 키보드 탭 이동을 지원한다. 탭은 방향키/Home/End로 전환한다. 애니메이션은 없다.

## 검증 기준
지원 입력 100개를 기존 Python 함수와 반올림 전후 비교한다. 기본 점수 31.32/64.77/43.78/86.43을 유지한다. 44구간에서 50%·60%의 헛경보/놓침은 2/0, 70%는 0/2, 항상 지참은 42/0이어야 한다. 미지원 입력 거절과 외부 의존성 부재를 확인한다. 실제 브라우저의 모든 사례 선택·초기화·키보드·좁은 화면·오프라인 파일 실행은 별도 화면 검증 대상으로 기록한다.

## 공유
같은 HTML을 로컬 발표와 Pages 게시에 사용한다. 기존 분석 브랜치에 소스와 빌드 방법, 검증 기록을 보관한다. Pages 설정 상태를 확인하고 활성화 권한이 없으면 설정을 변경하지 않고 필요한 설정을 안내한다. main 병합은 별도 작업이다.
