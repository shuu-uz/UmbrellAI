# 예보 평가·우산 추천 기준 초안

평가·추천 기준 초안입니다. 저장소에서 확인한 실제 컬럼 대응과 남은 확인 사항은 repository_findings.md를 참고하세요. 실제 예보 평가는 아직 수행하지 않았습니다.

## 담당·필요 컬럼

- 예보 담당: fcstDate, fcstTime, nx, ny, POP, pcp_raw, pcp_mm, pcp_type 및 baseDate/baseTime 또는 issued_at 제공.
- 실측 담당: date, time, nx, ny, 실제 강수량, rain_missing 제공. 강수량 이름은 미현님 확인 후 evaluate의 rain_column으로 지정합니다. 테스트의 actual_mm은 임시 이름입니다.
- 병합은 미현님 담당. 소현님은 결과 스키마·검사·평가·추천 기준 담당.

## 병합 결과 계약(협의 필요)

1. 시간대는 Asia/Seoul로 통일하고 날짜 YYYYMMDD, 시간 HHMM, 격자 정수로 정규화합니다. 원본 실측 date/time도 보존합니다.
2. 예보·실측의 강수량 단위와 집계 구간이 같아야 합니다. 관측소를 격자로 변환했다면 대응표와 방법을 남깁니다.
3. 대상 키는 fcstDate, fcstTime, nx, ny입니다. 대상 키마다 선택된 예보 한 행을 전달합니다.
4. 추천 판단 시점(decision_at) 이전 또는 같은 시각에 발표된 예보 중 가장 최근 발표를 선택하는 방안을 제안합니다. 실제 판단 시점은 팀에서 정합니다. 수집 시점(collected_at)과 발표 시점은 구별합니다.
5. 같은 발표·대상 키가 중복되어도 임의 삭제하지 않습니다. 출처/수집 기록을 확인해 해결합니다. 현재 평가 함수는 중복 대상 키를 오류로 처리합니다.
6. 발표 시각과 decision_at, 실측 관측 구간을 병합 결과에 보존합니다. 평가 함수는 병합 결과를 받아 계산하며, 시각 선택 및 기간 필터 자체는 구현하지 않습니다.

## 평가 기준(임시값)

- 비 예상: POP >= 50%. 비 실측: 실제 강수량 > 0 mm. 기준은 매개변수로 수정 가능합니다. 관측의 미량 강수 표현·해상도를 확인한 뒤 확정합니다.
- 강수 유형의 비/눈/혼합 구분이 가능한지 확인합니다. 실제 강수량만 있으면 결과는 엄밀히 '강수 발생 평가'이며 '비 평가'라고 단정하지 않습니다.
- rain_missing=1은 제외합니다. 잘못된 누락 플래그, 강수량 결측/음수, POP 결측/범위 밖 값도 제외하고 건수를 보고합니다.
- 오차행렬: 행은 실제 [없음, 있음], 열은 예상 [없음, 있음]. 결과는 [[TN, FP], [FN, TP]].
- 헛경보 비율(false_alarm_ratio) = FP/(TP+FP): 비 예상 중 실제 강수 없음.
- 거짓 양성률(false_positive_rate) = FP/(TN+FP): 실제 강수 없음 중 비 예상.
- 놓침률(miss_rate) = FN/(TP+FN): 실제 강수 있음 중 비 예상 못 함.
- 분모가 0이면 None입니다. 평가 행 수, 제외 건수, 기간·지역·임계값·발표 선택 기준을 결과와 함께 기록합니다.
- 실제 평가는 2026-10-07 이후 예보·실측의 시간/지역이 겹치는 기간만 사용합니다. 과거 실측만으로 예보 성능을 계산하지 않습니다.

## 추천 초안

입력은 이동 시간대에 선택된 시간별 POP/pcp_mm과 야외 이동 시간(분)입니다. 시간대별 최대값을 사용하며, POP를 시간별로 더하거나 독립 사건처럼 곱하지 않습니다.

- 시간당 예상 강수량 최대값 >= 1 mm이면 추천.
- POP 최대값 >= 50%이며 야외 이동 >= 15분이면 추천.
- 그 외 POP >= 50% 또는 예상 강수량 > 0이면 고려.
- 야외 이동 0분이면 우선순위 낮음. 예보 부족/잘못된 입력은 판단 자료 부족.
- 모두 설문·사용성 검토 전 임시 기준이며, 실제 필요성이나 성능이 검증된 규칙이 아닙니다. 이동 시간대 선택 및 강수 유형 처리는 상위 단계에서 수행해야 합니다.

설문은 상황별 선호 자료입니다. 실제 우산 필요 여부의 정답으로 사용하지 않습니다. 로지스틱 회귀는 예측 대상과 적절한 정답 데이터를 확보한 뒤 결정합니다.
